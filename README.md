# Newtonite Operations Management System

A full-stack work management application developed for the Newtonite Software Engineering Challenge.

## Project Overview

The application is designed to help teams manage operational work items, track workflow progress, control access based on user roles, and maintain an activity history.

## Planned Technology Stack

- **Frontend:** React and TypeScript
- **Backend:** Node.js, Express.js and TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Testing:** Vitest and Supertest

## Planned Features

- User authentication
- Role-based access control
- Work item creation, assignment and updates
- Workflow and approval validation
- Activity history
- Search, filtering and pagination
- Protection against conflicting updates
- Automated tests

## Project Structure

- `client/` — Frontend application
- `server/` — Backend API
- `docs/` — Engineering documentation

## Project Status

Initial repository setup and documentation are in progress. Application features will be implemented and tested incrementally.
